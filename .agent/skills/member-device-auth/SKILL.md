# Member Device Auth Procedure

Execute this procedure when building or updating member onboarding, initial device binding, and session setup workflows.

## Step 1: Prompt Activation Code
Prompt the member to enter the 1-time activation code generated by staff.

## Step 2: Validate Code and Unlinked Device Status
Query `Member` table for record matching `activationCode`. Follow `rules/schema.md` for model fields. Verify `deviceId` is null; fail activation if device is already linked.

## Step 3: Prompt 4-Digit PIN Setup
Prompt member to enter a new PIN. Follow `rules/thresholds.md` for PIN length specifications.

## Step 4: Hash PIN and Generate Device Identifier
Hash the PIN string using bcrypt. Generate a unique device identifier string for the current browser instance.

## Step 5: Bind Device to Member
Update `Member` table row setting `pinHash`, `deviceId`, and setting `activationCode` to null to prevent reuse.

## Step 6: Issue HTTP-Only Session Cookie
Generate a secure session token containing `memberId`. Set token in an HTTP-only secure cookie. Follow `rules/architecture.md` for server session handling.
